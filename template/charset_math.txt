# Phase 2 math collection charset — one entry per line, in capture order.
#   Same file format as charset_default.txt (see its header for the rules).
#   Scope decided by the user 2026-08-03: "every symbol that could plausibly
#   turn up in physics/maths", i.e. the confirmed 63 plus the expansion below.
#  --
#   NOT in this file (they need cells that are not the standard 84x132, so the
#   template generator adds them from an explicit spec, not from this list):
#     - oversized delimiters ( ) [ ] { } | written at full cell height, for
#       stretchy \left(...\right) assemblies
#     - horizontal pen strokes in wide cells (short / medium / long), used for
#       fraction bars and radical overbars, which MathJax emits as RULES
#       (rectangles) rather than glyphs — without these the page gets
#       ruler-perfect lines through otherwise handwritten equations
#  --
#   Aliased away on purpose (an existing store glyph is reused instead):
#     Greek capitals whose shape equals a Latin capital (A B E Z H I K M N O
#     P T Y X), omicron -> o, ring operator -> degree, dot operator -> middle
#     dot, and U+22EF horizontal ellipsis is synthesised from three middle dots.
