# archive/

Superseded material from before the iPad collection store (`glyphs/ipad`, 2026-08-05).

Kept rather than deleted: several of these are the only evidence behind decisions
recorded in `docs/STATUS.md`, and one of them (the paper store) is still what the
descender and stroke-weight measurements were cross-checked against. Nothing in
here is imported by the live pipeline or by `scripts/verify.sh`.

| Item | What it was |
|---|---|
| `glyphs_real_straight/` | de-slanted derivative of the paper store, an experiment that was not adopted |
| `handoff/`, `handoff2/` | render-comparison reports from earlier tuning rounds |
| `debug_images/` | scratch renders from baseline / spacing / effects tuning |
| `스캔본_1.pdf`, `스캔본_2.pdf` | the original paper template scans the paper store was built from |
| `straighten_glyphs.py` | built `glyphs_real_straight` |
| `tool2_report.py` | one-off registration-residual report for the paper splitter |
| `measure_scan_ink.py` | measured the scan ink statistics that `handwriting/style.py` and `feature_effects2_check.py` still cite as constants |
| `old_samples/` | demo .docx inputs and reference images from earlier tuning rounds; no check reads them |
| `spike_oneoff/` | spike tools nothing imports any more — `inventory.py` (+ its `input/` documents and `inventory.md`, which produced the charset frequency counts), `make_test_docx.py`, `make_overlays.py`, `compose_compare.py`. The LIVE math chain is `spike/parse_svg.py` + `tex2svg.js` + `render_placement.py`, driven by `scripts/render_docx_math.py`. |
| `spike_debug_evidence/` | the geometry-validation renders `spike/REPORT.md` and `docs/SOLVED.md` cite as evidence (e.g. `geom_anchor_ab_eq1.png`); those documents were re-pathed here |
| `ipad_pilot_export_matrix/` | the four GoodNotes export-variant PDFs used once to pick the canonical export recipe; the recipe itself is recorded in `docs/STATUS.md` |
| `Thermodynamics_..._Lecture_Notes.pdf` | the lecture-notes reference stroke weight was measured against; the user ruled it out as a target (another person's hand) |

Membership was decided by sweeping every file against what `scripts/`,
`handwriting/`, `spike/*.py` and `verify.sh` actually reference, not by age.

## Deliberately NOT archived

`glyphs/real` (the paper store) stays in place: `scripts/feature_effects2_check.py`
renders with it to assert the composited ink-tone target, so it is a live
dependency of the verify suite, not leftovers. Same for `template/ipad_pilot/`,
which `feature_ipadpilot_check.py` regenerates.

`scans/ipad_pilot/TalkFile_template 2.pdf` also stays: it is the 31-page GoodNotes
export that `glyphs/ipad` was extracted from — the one file here that could not be
recreated without rewriting every cell by hand. It is gitignored, so it exists only
on this disk.

`out/` and `spike/out/` are not archived at all — they are regenerated by
`verify.sh` and `scripts/render_docx_math.py`, so they are deleted rather than kept.
